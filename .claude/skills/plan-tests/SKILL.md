Feature: $ARGUMENTS

1. Open https://www.saucedemo.com with the Playwright tools
   and explore the feature. Do not guess: look.
2. Write test cases as a Markdown table:
   ID | Scenario | Steps | Expected result
3. Cover happy path, negative, boundary and security cases.
4. Mark anything you could not verify as "ASSUMPTION".
